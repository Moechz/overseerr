# Changelog

All notable user-visible changes to the Overseerr TOS application package.

## 1.35.0-1 — 2026-11-11

### Added
- First release. Overseerr (`linuxserver/overseerr:1.35.0`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8089 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/overseerrdocker/`.
